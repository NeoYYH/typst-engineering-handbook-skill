# 工程手册 Typst 风格

可复用的 Cursor / Grok Bot skill：用统一视觉与写作节奏写中文工程解读、协议与架构手册（Typst → A4 PDF）。

## 文件

- [`SKILL.md`](./SKILL.md) — skill 正文（YAML frontmatter + 配方）

## 用途

写中文工程手册时按本风格：青绿/亮蓝/橙配色、初学者导读、证据边界、列举→分项、陷阱与优化清单、PDF + 预览 + NOTES 交付。

## 在 Cursor / Grok Bot 中使用

将本仓库的 `SKILL.md` 放到助手的 skills / workflows 目录（或按产品文档安装 skill），描述字段会告诉助手何时自动加载。

## 许可

按仓库所有者意愿另行补充。内容来自个人工程手册实践沉淀，可自由改编。
